# 🌐 Mohd Sahil Ansari - Portfolio Website

A personal portfolio website built with **HTML & CSS** to showcase my professional journey, resume, and highlighted projects in **Data Science, Machine Learning, and Fraud Analytics**.  
This site serves as a central hub for recruiters and collaborators to explore my work and connect with me.

---

## 📌 Features
- **About Section** — Brief introduction highlighting my background in Data Science & ML.  
- **Resume & Cover Letter** — Direct links to downloadable PDF files.  
- **Projects Showcase** — Highlighted ML projects with GitHub links:
  - Fraud Detection & Transaction Risk Scoring  
  - Movie Recommendation System  
  - SMS Spam Classifier  
- **Contact Section** — Email, phone, and GitHub profile links.  
- **Responsive Design** — Clean and professional layout using HTML & CSS.
